> и публикуется на **GitHub Pages**.

## Описание игры

"Легенда об Анге, Повелитель Народов" - это стратегическая карточная игра, где вы управляете балансом четырех народов: Народа Огня, Племени Воды, Царства Земли и Кочевников Воздуха. Ваша цель - поддерживать гармонию между народами, принимая решения, которые влияют на их ресурсы.

## Цель игры

провести как можно больше времени не убив ни один из народов и не приведя один из народов к излишнему процветанию.

## Как запустить игру

### Онлайн (GitHub Pages)

Игра автоматически публикуется на GitHub Pages при каждом пуше в ветку `main`.
Откройте страницу сайта в браузере — никакой установки не требуется.

> Не забудьте в настройках репозитория (**Settings → Pages → Build and deployment → Source**)
> выбрать **GitHub Actions**.

### Локально

Вся игра — это статические файлы из папки `renderer/`. Открыть её можно любым из способов:

```bash
# Вариант 1: через npm-скрипт (запускает локальный сервер на папке renderer/)
npm start

# Вариант 2: любой статический сервер, например Python
python -m http.server 8000 --directory renderer
# затем откройте http://localhost:8000
```

Достаточно просто открыть файл `renderer/index.html` в браузере — сборка и зависимости не требуются.

### Как играть

### Основные механики

1. **Карточки ситуаций**: Каждую эпоху вам представляется ситуация, требующая решения. Адаптируйте окно чтобы вы видели всё содержимое - игра рассчитана на большие мониторы.
2. **Выбор**: Вы можете принять или отклонить предложение, свайпнув карточку:
   - **Свайп вправо** или кнопка "Принять" - согласиться с предложением
   - **Свайп влево** или кнопка "Отклонить" - отказаться от предложения
   - Вы также можете нажать на кнопку есть проскроллите по центру экрана при помощи колёсика мышки
3. **Ресурсы**: Каждое решение влияет на ресурсы четырех народов:
   - 🔥 Народ Огня
   - 💦 Племя Воды
   - 🗻 Царство Земли
   - 💨 Кочевники Воздуха
4. У каждого в начале влияние 10, в зависимости от ваших действий в каждую эпоху значения будут меняться. Старайтесь продержать баланс.

### Интерфейс

- **Счетчик эпох**: Показывает, сколько эпох (ходов) вы прожили
- **Панель ресурсов**: Отображает текущие ресурсы каждого народа (шкала от 0 до 20)
- **Карточка ситуации**: Текущая ситуация с вариантами решения
- **Предпросмотр изменений**: При свайпе показывает, как изменятся ресурсы

### Индикаторы состояния ресурсов

- **🔴 Критический (≤ 3)**: Ресурс на грани истощения, мигает красным
- **🟡 Предупреждение (≤ 6)**: Ресурс низкий, выделен оранжевым
- **🟢 Максимальный (≥ 18)**: Ресурс близок к максимуму, выделен зеленым

## Стратегия

- **Баланс**: Старайтесь поддерживать баланс между всеми народами
- **Предвидение**: Обращайте внимание на предпросмотр изменений перед принятием решения (!), Если потянуть за карточку влево или вправо вы увидите как изменятся значения.
- **Адаптация**: Реагируйте на критические ситуации, когда ресурсы становятся низкими

## Технические особенности

Игра не имеет внешних зависимостей и не требует сборки — это чистый HTML/CSS/JavaScript.

- Все игровые ситуации берутся из встроенного набора строк (без обращения к сети/LLM), поэтому игра работает полностью офлайн.
- Управление:
  - **Мышь/тач**: потяните карточку для свайпа
  - **Кнопки**: "Принять"/"Отклонить"

### Адаптивность

Игра автоматически подстраивается под размер экрана:

- **Десктоп**: Оптимальное расположение элементов для большого экрана
